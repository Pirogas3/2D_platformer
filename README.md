> *«Golden Wake» — это мой первый завершённый проект на Unity.
Это 2D платформер с пиксельной графикой, в котором я реализовал гибкую систему инвентаря, прокачку, диалоги, систему локализации и сохранение всех необходимых игровых данных в JSON.
Проект создан как портфолио для демонстрации моих компетенций в проектировании архитектуры, ООП, UI/UX и геймдизайне. Я рассматриваю возможность работы в команде, где смогу развиваться и приносить пользу.
Кроме того, у меня есть опыт в создании текстур (Aseprite, Photoshop) и 3D-моделировании (Maya, 3ds Max, Blender), что даёт мне более глубокое понимание полного цикла разработки видеоигр.*

## ✨ Особенности

- **Управление игровым персонажем** – точное управление персонажем: движение, прыжки, двойной прыжок, атака в ближнем и дальнем бою и т.д.
- **Враги** – различные виды противников, есть те, чья логика реализована через корутины, а есть те, что реализованы через состояния и методы Update.
- **Боевая система** – ближний бой с легкой настройкой хитбоксов оружия разных форм (круг, прямоугольник, конус), дальний бой реализован в виде снарядов. Урон рассчитывается по формуле с учётом атаки (атакующего) и защиты (защищающегося).
- **Инвентарь и экипировка** – полноценная система инвентаря с ячейками, перетаскиванием между ячейками или другими инвентарями, с методами наподобие "взять всё", с возможностью использования контейнеров внутри другого инвентаря (сумки, колчаны, кошельки), и модификаторами веса *(в конечную игру вес предметов и сумки не вошли за ненадобностью, но для их использования всё готово)*. Предметы можно использовать, экипировать, выбрасывать, назначать в ячейку быстрого доступа.
- **Система прокачки** – получение опыта, повышение уровня, очки характеристик которые можно тратить на улучшение параметров: здоровье, атака, защита, скорость (передвижения). Перки (например, двойной прыжок) покупаются за игровую валюту.
- **Диалоги и локализация** – диалоговое окно с анимированной посимвольной печатью, поддержка локализации через Excel (SheetX Pro). Язык можно переключать в настройках в любой момент.
- **Сохранения** – несколько слотов файловых сохранений (быстрое, авто сохранения). Сохраняется состояние игрока, инвентарь, прогресс, содержимое сундуков, состояние объектов (включён/выключен, удалён) и их местоположение (если они подвижные). Автосохранение циклически перезаписывает 3 слота. А быстрое сохранение доступно на F5, загрузка - F9, в любой момент игры.
- **Интерактивное окружение** – сундуки, рычаги (переключатели), чекпоинты, подвижные объекты, разрушаемые объекты и спавн осколков, собираемые предметы.
- **UI и визуальные эффекты** – кастомизированные виджеты (прогресс-бары, тултипы, контекстное меню), анимации для кнопок, экран загрузки, партиклы.

## 🛠 Технологии

- **Движок**: Unity 2022.3.62f3.
- **Язык**: C# (.NET Standard 2.1).
- **Архитектура**: Компонентный подход, синглтоны, интерфейсы, события.
- **Ввод**: Input System (поддержка клавиатуры, мыши, геймпады).
- **Камера**: Cinemachine + Pixel Perfect Camera.
- **UI**: Unity UI.
- **Локализация**: SheetX Pro (Excel → JSON/C#).
- **Сохранения**: JSON через `JsonUtility`, файловая система (Documents/).

## 💻 Установка и запуск

### Запуск готовой сборки (для игроков)
1. Скачайте последнюю версию игры со страницы [Releases](https://github.com/Pirogas3/2D_platformer/releases) (выберите файл для вашей ОС).
2. Распакуйте архив и запустите исполняемый файл:
   - **Windows** – `Golden Wake.exe`
   - **Linux** – `Golden Wake.x86_64`
   - **macOS** – `Golden Wake.app`
3. Игра создаст папку `Golden Wake` в папке `Documents` для сохранений.

### Запуск из исходников (для разработчиков)
1. Клонируйте репозиторий.
2. Откройте проект в Unity 2022.3.62f3 (или новее).

## 🎮 Управление

- **Перемещение**: W A S D
- **Прыжок**: Space
- **Атака ближнего боя**: Левая кнопка мыши
- **Атака дальнего боя**: Правая кнопка мыши
- **Взаимодействие (двери, диалоги, сундуки)**: E
- **Использовать предмет из быстрого слота**: Q
- **Смена ячейки быстрого доступа**: клавиши 1 ... 6, или колесико мыши
- **Перетаскивание объектов**: F
- **Открыть инвентарь**: I
- **Открыть меню персонажа (с уровнями, прокачкой характеристик и перками)**: K
- **Активировать щит (если прокачен соответствующий перк, эдакая неуязвимость на короткое время)**: C
- **Быстрое сохранение**: F5
- **Быстрая загрузка**: F9
- **Управление элементами интерфейса**: привычное управление мышью, скролл мышью, скип диалогов на Space или щелчок левой кнопкой мышью и т.д. ПКМ в инвентаре по предмету для вызова контекстного меню взаимодействия. Всплывающие подсказки при наведении мыши.

## 🧱 Архитектура проекта

Проект построен на **компонентной архитектуре** с чётким разделением ответственности. Ключевые системы слабо связаны, используют события, интерфейсы и синглтоны. В некоторых классах (например, `Hero` и `InventoryData`) объём кода превышает средний — это осознанное решение, так как проект разрабатывался как портфолио с акцентом на демонстрацию механик, а не на микро-архитектуру. Я вижу возможности для рефакторинга и в коммерческом проекте выделил бы на это время на ранних этапах.

Ниже представлены основные системы с пояснением их внутреннего устройства и ключевых классов.

---

### 🔷 Глобальное состояние и сохранения

- **GameSession** — синглтон, управляющий состоянием игры, сценами, HUD и экраном загрузки.
- **PlayerData** — контейнер всех данных игрока: инвентарь, прокачка, перки, здоровье, экипировка, позиция и текущая сцена. Сериализуется в JSON.
- **EnviromentData** — состояние окружения: активированные чекпоинты, содержимое сундуков, состояние объектов (включён/выключен, удалён) и позиции подвижных объектов.
- **SaveManager** — статический класс для работы с JSON-файлами в папке `Documents/Golden Wake/Saves`. Поддерживает несколько слотов (QuickSave, AutoSave с циклической перезаписью 3 слотов).
- **Генерация уникальных ID** — для объектов, состояние которых нужно сохранять (`ChestComponent`, `CheckPoint`, `PersistentObjectState`), ID генерируется автоматически на основе имени объекта и его координат (например, `"Chest_3.5_2.1"`). Это гарантирует стабильность ID между сессиями и не требует ручного заполнения в инспекторе. ID можно также задать вручную при необходимости.

---

### 🎒 Инвентарь и предметы

- **InventoryData** — контейнер предметов с поддержкой добавления, удаления, стакинга и перемещения между инвентарями. Также реализована поддержка контейнеров (сумки, колчаны) и модификаторов веса — механика готова, но не используется в финальной версии. Это сделано как задел для будущих проектов.
- **InventoryItemCell** — UI-ячейка, поддерживающая перетаскивание (drag&drop), контекстное меню (ПКМ) и универсальные тултипы. Управляет подсветкой при наведении и прозрачностью при перетаскивании.
- **InventoryWindowController** / **ChestInventoryController** — управляют окнами инвентаря игрока и сундуков соответственно. Поддерживают перетаскивание между инвентарями и синхронизацию с данными.
- **QuickInventoryController** — 6 слотов быстрого доступа, которые можно заполнять перетаскиванием из инвентаря. Состояние слотов сохраняется в `PlayerData.QuickSlots` и восстанавливается при загрузке.
- **Контекстное меню** — динамически создаётся при ПКМ по предмету, показывает действия (использовать, выбросить, очистить слот, экипировать/снять). Видимость кнопок зависит от категории предмета и источника.
- **DefsFacade** — ScriptableObject-фасад для централизованного доступа к определениям предметов, их свойств и перков. Легко расширяется новыми фасадами.

---

### ⚔️ Боевая система

- **AttackHitbox** — настраиваемая область поражения (круг, прямоугольник, конус) с поиском целей по тегу или слою. Форма и параметры задаются в инспекторе. Делегирует нанесение урона `DamageComponent`.
- **DamageComponent** / **HealthComponent** — модули для нанесения и получения урона. `HealthComponent` вызывает события `OnDamage`, `OnHeal`, `OnDie`, что позволяет легко привязывать др. необходимые методы или визуальные/звуковые эффекты.
- **DamageCalc.CalculateDamage()** — статический метод для расчёта итогового урона по формуле с учётом атаки и защиты.
- **Projectile** — снаряды для дальнего боя. Движение реализовано через `Rigidbody2D.MovePosition`. Урон передаётся через `DamageComponent` при спавне снаряда.

---

### 🤖 Искусственный интеллект врагов

- **EnemyBotAI** — реализация ИИ на корутинах (патруль, преследование, атака, кулдаун). Удобна для простых сценариев с последовательными действиями.
- **BaseAI** — альтернативная реализация на Update-состояниях (конечный автомат). От неё наследуются др. мобы-враги, например `PinkStarAI` с механикой чарджа.
- **TotemGroupAI** / **TotemHeadAI** — ИИ для врагов типа «турель» и «матрешка». Урон распределяется по головам сверху вниз, коллайдер динамически уменьшается при уничтожении голов.
- **Patrol** (`SpotPatrol`) — система патрулирования по точкам с настраиваемой паузой и точностью достижения.

---

### 📜 Диалоги и локализация

- **DialogBoxController** — управляет диалоговым окном с посимвольной печатью. Поддерживает пропуск (пробел или клик), события открытия/закрытия, интеграцию с локализацией.
- **ShowDialogComponent** — триггер для запуска диалога. Поддерживает два режима: привязка к `DialogData` (в инспекторе) или к `DialogDef` (ScriptableObject).
- **SheetX Pro** — локализация через Excel → JSON → C#. Язык можно переключить в настройках в любой момент игры.

---

### 📈 Прокачка и перки

- **LevelData** — опыт, уровни и очки характеристик. Прогрессия опыта рассчитывается по формуле `500 * 1.1^(level-1)`. При повышении уровня выдаётся 1 очко характеристик.
- **StatUpgradeData** — количество улучшений для каждой характеристики. Каждое улучшение повышает характеристику на заданное (настраиваемое для каждой характеристики) значение.
- **PerkData** — состояние перков (уровень, куплен/не куплен). Перки дают новые способности (двойной прыжок, щит, мультивыстрел, телекинез).
- **StatUpgradeButton** — UI-компонент для прокачки характеристик. Проверяет наличие очков, максимальный уровень улучшения и обновляет состояние кнопки в реальном времени.
- **ShieldAbility** — пример временной способности: активируется по нажатию, даёт +100 к защите на 3 секунды, затем кулдаун 15 секунд. Спавнит партикл и уведомление.

---

### 🖥️ UI и визуальные эффекты

- Все UI-элементы построены на Unity UI (Canvas, TextMeshPro).
- **Кастомные виджеты**: прогресс-бары (`ProgresBarWidget`), тултипы (`TooltipView`, `TooltipManager`), контекстное меню (`InventoryContextMenu`), анимированные кнопки (`BreathingAnimation`, `ScrollButton`).
- **FloatingTextManager** — спавн текста в мировых координатах. Используется для уведомлений (опыт, эффекты зелий, заряд мультивыстрела и т.п.). Текст плавно поднимается и исчезает.
- **EscController** — управление стеком окон меню (пауза, настройки, загрузка). Закрывает окна по Esc в обратном порядке.
- **ContextMenuManager** — глобальный менеджер контекстного меню. Спавнит меню в позиции курсора с учётом границ экрана, автоматически закрывает при клике вне меню или по Esc.

---

### 🧩 Система взаимодействия с окружением

- **InteractableComponent** — базовый класс для интерактивных объектов (сундуки, чекпоинты, двери). Использует `UnityEvent<GameObject>` для гибкой настройки действий в инспекторе.
- **EnterTriggerComponent** / **EnterCollisionComponent** — триггеры и коллизии, фильтруемые по тегу или слою. Вызывают события с передачей `GameObject` объекта, вошедшего в зону.
- **ChestComponent** — сундук с инвентарём. Сохраняет содержимое в `EnviromentData`, автоматически закрывается при отдалении игрока. При открытии/закрытии проигрывает анимацию.
- **CheckPoint** — чекпоинт с уникальным ID. При активации сохраняет ID в `EnviromentData` и выполняет автосохранение. Анимация объекта меняется в зависимости от состояния (поднимается флаг при активации).
- **DraggableObject** — подвижные объекты (телекинез и перетаскивание клавишей F). При перетаскивании гравитация снижается, коллизии с героем не отключаются (чтобы сохранить естественность физики). Телекинез доступен только при прокачанном перке и отсутствии оружия.
- **DestroyObjectComponent** / **DestroyAndRegistry** — уничтожение объектов с регистрацией в `EnviromentData` (для удаления объектов при загрузке).

### ✨ Интересные технические решения

- **Генерация уникальных ID** — для объектов, которые должны сохранять состояние (чеки, сундуки, подвижные объекты), ID генерируется автоматически на основе имени объекта и его координат (например, `"Chest_3.5_2.1"`). Это гарантирует стабильность ID между сессиями и не требует ручного заполнения в инспекторе. При необходимости ID можно задать вручную.
- **Динамическое изменение коллайдера тотема** — при уничтожении головы коллайдер уменьшается пропорционально оставшемуся количеству голов, а смещение корректируется так, чтобы нижняя граница оставалась на месте. Это достигается сохранением начальных размеров и пересчётом в реальном времени.
- **Универсальный тултип** — работает с любыми элементами UI (инвентарь, перки, характеристики) и автоматически определяет ключи локализации по шаблону `{id}_Header`, `{id}_Description`, `{id}_Cost`.
- **Перетаскивание мышью (телекинез)** — предметы можно перемещать мышью в радиусе действия, при этом они следуют за курсором; при выходе за пределы радиуса предмет отпускается.
- **Интеграция локализации** — диалоги и UI используют общий источник (Excel → JSON), что позволяет переключать язык без перезапуска игры.
